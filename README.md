# PRS UI

A centralized, reusable UI component library for Web and Mobile applications across the PRS ecosystem.

## Packages

| Package | Description |
|---|---|
| `@prs/ui-web` | Shared UI components for React and Next.js. |
| `@prs/ui-native` | Shared UI components for React Native CLI. |
| `@prs/ui-shared` | Common types, utilities, and shared resources. |

## Tech Stack

- TypeScript
- React & Next.js
- React Native CLI
- pnpm Workspaces
- Modern build tooling

## Purpose

Provide a scalable, maintainable, and consistent UI component ecosystem with independently managed packages for Web and Mobile applications.

## Project Status

**Initial Setup – In Progress**

Currently establishing the monorepo architecture, package configurations, and development infrastructure. Component development will be introduced in future phases.
