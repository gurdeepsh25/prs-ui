# @prs/ui-shared

Platform-agnostic foundation for the PRS UI ecosystem: common TypeScript types,
utilities and (in future phases) design tokens shared by [`@prs/ui-web`](../ui-web)
and [`@prs/ui-native`](../ui-native).

> **Status:** Initial setup — no public API is exported yet. Component and
> utility development starts in a later phase.

## Consumers

| Package          | Relationship                                                  |
| ---------------- | ------------------------------------------------------------- |
| `@prs/ui-web`    | peer dependency (web components + shared primitives)          |
| `@prs/ui-native` | peer dependency (React Native components + shared primitives) |

This package must never import from `react`, `react-dom`, or `react-native`.
Keeping it runtime-free guarantees both platform packages can depend on it
without conflicts.

## Commands (run from repository root)

```sh
pnpm --filter @prs/ui-shared build      # ESM + CJS bundles + type declarations
pnpm --filter @prs/ui-shared typecheck  # strict tsc check
pnpm --filter @prs/ui-shared clean      # remove dist/
```

## Build outputs

- `dist/index.js` / `dist/index.cjs` — tree-shakable ESM & CJS bundles (tsup)
- `dist/types/*.d.ts` — type declarations generated by `tsc`
- `sideEffects: false` — safe for aggressive bundler tree-shaking

Publishing is managed with [Changesets](../../.changeset); see the root README.
